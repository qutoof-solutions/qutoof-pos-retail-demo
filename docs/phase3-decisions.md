# سجل قرارات المرحلة الثالثة

**التاريخ:** 2026-10-11  
**الفرع:** `feature/phase-3-emr-digital-tickets-calendar-shift-close`

## قرارات معتمدة

- **EMR v1:** سجل سريري منظم يتضمن العلامات الحيوية، الحساسية، المشكلة/التشخيص، التقييم، الخطة، والمتابعة.
- **الوصفة المنظمة:** مسموحة ضمن EMR v1 بالحقول: المادة، الجرعة، الوحدة، التكرار، المدة، طريق الإعطاء، والتحذيرات.
- **التداخلات الدوائية:** غير متاحة في هذه المرحلة. لا توجد قاعدة أدوية معتمدة، ولا يدّعي النظام فحص التداخلات.
- **صلاحيات السجل والمرفقات:**
  - الطبيب/الأخصائي يقرأ ويكتب فقط لسجلات المرضى المرتبطة بمواعيد مسندة إليه.
  - المالك/المدير يقرأ كل سجلات المنشأة ويستطيع التصحيح المدقق.
  - الاستقبال لا يرى نص السجل أو المرفقات ولا يملك إلا بيانات الموعد.
  - أمين المخزن لا يصل إلى السجلات السريرية.
- **Gate Check-in:** رمز مستقل غير قابل للتخمين، لموعد واحد، للفرع والمستأجر نفسيهما، ضمن نافذة 60 دقيقة قبل الموعد حتى 30 دقيقة بعده؛ يبطل عند الإلغاء أو إعادة الجدولة. التصحيح اليدوي للمالك/المدير/الاستقبال بسبب إلزامي وتدقيق.
- **تقفيل الوردية:** مطابقة تفصيلية لكل وسيلة دفع وصندوق وربط التحصيل بالفاتورة والفرع والمستخدم والوردية، مع سجل عكوس ومدقق. المصروفات والديون وصافي الربح مؤجلة.
- **الاحتفاظ:** لا حذف آلي للسجلات الطبية أو المالية في هذه المرحلة.

## حدود الحزمة الحالية

تبدأ هذه الحزمة بالجزء السريري المنظم فقط. كل تغييرات قاعدة البيانات additive، وتُختبر على SQLite/بيانات اصطناعية. لا تُطبق أي migration على D1 الإنتاجية ولا يُنشر التطبيق إلى الإنتاج ضمن هذه الحزمة.

لا يُنشئ النظام تشخيصًا أو توصية علاجية من تلقاء نفسه، ولا يضيف قاعدة أدوية أو فحص تداخلات. الحقول المنظمة هي وسيلة تسجيل لما يدخله المستخدم المخول فقط.
